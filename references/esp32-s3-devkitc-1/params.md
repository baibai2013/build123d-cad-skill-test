## 坐标系契约(★ 关键,所有下游代码必读)

### 世界坐标系定义
- **世界原点 (0,0,0)** = bottom shell **外底面几何中心**
- **X 轴** = PCB 长边方向(沿 62.74mm 方向)
- **Y 轴** = PCB 短边方向(沿 25.40mm 方向)  
- **Z 轴** = 垂直向上

### PCB 本地 → 世界变换
PCB 放置在外壳内,PCB 本地 (0,0) 角映射到世界坐标:

```
pcb_origin_world = (
    x = -PCB_L / 2,                       # PCB 沿 X 居中 → 左下角 X
    y = -PCB_W / 2,                       # PCB 沿 Y 居中 → 左下角 Y  
    z = base_t + pcb_standoff             # 底板厚 + PCB 悬空间距
)
```

**所有 B/C/D/E/F 节中的坐标通过此 Location 变换为世界坐标**。例如:

```python
# ✅ 正确:一次定义,全局使用
pcb_origin = Location((-PCB_L/2, -PCB_W/2, base_t + pcb_standoff))
j2_world = pcb_origin * Location((6.00, 3.66, 0))   # J2 世界坐标
sw1_world = pcb_origin * Location((6.76, 13.79, 0)) # Boot 按键世界坐标

# ❌ 错误:现场凑偏移
j2_x = 6.00 + 3.8  # 3.8 从哪来?下次改壁厚就漂移
```

**下游代码禁止再出现"+ PCB 定位偏移"这种未定义的变量**。

## 装配拓扑决策

### G. 外壳方案:**盖板夹持式**(方案 A)

**选型理由**:
- 无螺孔 + 排针下方针脚 3.5mm 长 → 不能"从顶部丢入"(会刮底板)也不能"从短边滑入"(USB 占位挡路)
- **最可行路径**:PCB 放到底壳的 4 角低台上(低于 PCB 顶面),合上盖板时盖板内侧 4 角压舌恰好顶在 PCB 上表面 4 角,通过 snap-fit 闭合后 PCB 被"上下夹住"

### 装配序列(机械师操作描述)
1. PCB 放入底壳,四角搁在 4 个低台上(低台高度 = 悬空间距)
2. PCB 底面距底壳内底面 4 mm(容纳背面元件 + 排针下方针脚)
3. 盖板 4 角压舌朝下凸出 0.5mm,接触 PCB 上表面
4. 盖板侧壁 snap-fit 扣入底壳外壁凹槽,PCB 被夹紧

### G1. 外壳主体参数
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 底壳外形长 × 宽 | `PCB_L + 2×(wall + gap)` × `PCB_W + 2×(wall + gap)` | 下游用 PCB 尺寸算,禁止硬编码 "71×32" |
| 壁厚 `wall` | 2.0 mm | FDM 打印 5 周可靠 |
| 底板厚 `base_t` | 2.0 mm | 从 1.5 改 2.0,防止 71×32mm 底面翘边 |
| 顶罩厚 `lid_t` | 2.0 mm | 同理 |
| PCB 装配间隙(单侧) `gap` | +0.4 mm | 从 0.3 放宽 0.1,FDM ±0.2~0.3mm 公差安全 |
| PCB 悬空间距 `pcb_standoff` | 4.0 mm | 从 3.5 加 0.5 余量,容纳背面排针 3.5mm + 余量 |

### G2. 盖板净空(★ 关键不变量)
**下游必须选择一种场景建模,不得模棱两可**:

| 场景 | 盖板净空 `lid_clearance` | 盖板总高 `lid_h` 推荐 | 说明 |
|------|------------------------|---------------------|------|
| 不焊排针(裸板) | ≥ 模块高 + 0.5 = 3.6 mm | 5.6 mm | 紧凑型外壳,只能用裸板 |
| 焊排针(最常见) | ≥ 排针上方 + 0.5 = 9.0 mm | 11.0 mm | max(模块 3.1, 排针 8.5) + 余量 |

**本建模默认选"焊排针"场景**(DevKit 主流用法)。下游参数:`lid_clearance = 9.0`。

### G3. 4 角低台 + 盖板压舌(PCB 夹持机构)
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 4 角低台高度(底壳) | `pcb_standoff` = 4.0 mm | PCB 搁在低台顶面 = Z_pcb_bottom |
| 4 角低台平面边长 | 3.0 × 3.0 mm | 足够支撑 PCB 角,不遮任何元件 |
| 4 角低台定位 | PCB 本地 4 角,各向外 1.5mm | 贴 PCB 角但在 PCB 外缘内 |
| 盖板压舌 Z 凸出 | 0.5 mm | 盖板合上后压在 PCB 上表面 |
| 盖板压舌平面边长 | 3.0 × 3.0 mm | 与底座低台对齐 |
| 压紧路径 | 1.6 mm (= PCB 厚) | PCB 总占用 Z 空间 = 1.6 mm |

> 注:设计意图是 PCB 上下 0 间隙夹紧。FDM 误差 ±0.2mm,实际打出来可能有 0.2-0.4mm 松紧差。若打出来太松,加薄垫片;太紧,挫压舌。

## I. Snap-fit 卡扣参数(完整版)

**方向**:盖板侧壁内扣(凸起朝内)插入底壳侧壁凹槽,合上时弹性形变一次。

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 卡扣数量 | 2 对(短边各 1 对) | 对称分布 |
| 卡扣宽度 | 6.0 mm | 接触面积 |
| **卡扣悬臂长度** | 6.0 mm | 从盖板侧壁与底壳内壁接触处算起,决定弹性模量 |
| **卡扣头厚度** | 0.8 mm | 凸出量(插入干涉量) |
| **卡扣头导角** | 45° × 0.4 mm | 辅助合盖,降低插入力 |
| 底壳对应凹槽宽度 | 6.2 mm(卡扣宽 + 0.2 mm) | 左右让位 |
| 底壳对应凹槽深度 | 0.9 mm(卡扣头 + 0.1 mm) | 扣入深度余量 |
| 扣向 | 内扣(盖板凸朝内) | 外观整洁,无外侧凸起 |
| 卡扣根部 Z(距盖底内面) | 2.0 mm | 悬臂起点,盖板侧壁下 2mm 处开槽给悬臂让位 |
| 卡扣头 Z(距盖底内面) | 8.0 mm | 根部 + 悬臂长 = 2 + 6 |

### 失效模式提醒
- **PLA 打印**:悬臂 6mm + 头厚 0.8mm 反复插拔 5-10 次后弹性疲劳,适合一次装配
- **PETG 打印**:弹性更好,可反复多次
- **层线方向关键**:悬臂层线若沿 Z 平行,弯曲时层间断裂;建议**悬臂沿 XY 平面平躺打印**(需支撑),或增加壁厚

## 建模约束(关键不变量,强制)

### 约束 1:USB 孔对齐
```python
# 底壳前端 USB 开孔中心 X 由 J2/J4 PCB 本地坐标 + pcb_origin 变换得出
usb1_world = pcb_origin * Location((J2_X, 0, 0))   # Y=0 因为连接器在板前端边
# 开孔中心 X 必须匹配 usb1_world.position.X(± 0.3mm)
```

### 约束 2:按键压柱对齐
```python
sw1_world = pcb_origin * Location((SW1_X, SW1_Y, 0))
# 盖板 Boot 压柱中心(X,Y) 必须匹配 sw1_world.position.(X,Y)(± 0.3mm)
```

### 约束 3:盖板净空
```python
# 焊排针场景(默认):
lid_clearance >= max(module_h, header_top_h) + safety_margin
            >= max(3.1, 8.5) + 0.5 = 9.0 mm
# 不焊排针场景:lid_clearance >= 3.6mm
```

### 约束 4:悬空间距 vs 排针下方
```python
pcb_standoff >= header_bottom_h + safety_margin
            >= 3.5 + 0.5 = 4.0 mm
```

### 约束 5:PCB 四角低台不遮元件
- 低台平面边长 ≤ 3.0 × 3.0 mm
- 低台定位:PCB 4 角朝板内 1.5mm 内侧 → 覆盖 (0~3, 0~3) / (59.74~62.74, 0~3) 等 4 个小角区
- **要求**:PCB 这 4 个角 3mm 区域内无 SMD 元件(视觉确认 + DXF 层检查)

### 约束 6(工艺):FDM 打印方向
- 底壳:开口朝上打印,无悬臂,支持 0
- 盖板:内侧朝上打印(压柱和卡扣悬臂朝上),避免悬空桥接
- 若卡扣悬臂打印有困难,改为 PETG 或增加卡扣壁厚至 1.2mm

## Dave Cowden review 后的变更记录

本版本针对以下问题做了修正:
1. **加坐标系契约**(新节):定义 pcb_origin_world 一次,下游代码禁止再出现 "+ PCB 定位偏移" 未定义变量
2. **盖板净空按场景分裂**:焊排针 9.0mm / 不焊 3.6mm,不再混淆
3. **装配路径明确**:选方案 A 盖板夹持,描述 PCB 装配序列(机械师操作)
4. **删除冗余派生量**:USB 间距 / 按键间距不再单列,由下游代码减法派生
5. **Snap-fit 参数补全**:增加悬臂长度 / 头厚 / 扣向 / 打印方向 / 失效模式
6. **悬空间距 3.5→4.0**:给排针下方 0.5mm 余量
7. **PCB 间隙 0.3→0.4**:FDM 公差更稳
8. **底板 / 顶罩 1.5→2.0**:抗翘边
